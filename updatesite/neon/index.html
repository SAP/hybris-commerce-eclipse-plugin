Eclipse p2 Repository

This directory hosts the Eclipse p2 update site for the hybris commerce eclipse plugin (Eclipse Plugin for SAP Commerce).

Available Update Sites

  • latest/ — Latest published Eclipse p2 repository
  • neon/ — Eclipse p2 repository (neon)

How to Install in Eclipse

  1. Open Eclipse and select Help → Install New Software…
  2. Click Add… and enter the latest/ or neon/ URL as the Location.
  3. Select SAP Commerce, development tools for Eclipse and follow the installation wizard.

Note: p2 repository directories contain Eclipse metadata (content.jar, artifacts.jar, p2.index) for Eclipse’s installer rather than browsable HTML pages.
